# 提示词重构设计文档

**日期**：2026-06-28  
**目标文件**：`backend/app/engines/ai/chat_provider.py`

## 背景与问题

当前视频生成存在以下视觉质量问题：
1. 字体大小不受控，默认值导致文字过大或不一致
2. 元素渲染粗糙，动画单调
3. 未声明画布安全区，元素频繁超出屏幕
4. 视觉风格偏暗沉，缺乏活力
5. 元素未及时退场，导致后续镜头元素重叠

## 方案：双阶段彻底重构

### 阶段划分原则

| 阶段 | 函数 | 职责 |
|---|---|---|
| 叙事生成 | `generate_narrative` | 旁白 + 画面意图（弱技术层描述） |
| 代码生成 | `generate_code` | 全部渲染规范，AI 按 description 意图翻译成代码 |

---

## 第一部分：叙事阶段重构（`_NARRATIVE_ENGINE_HINTS`）

### 描述粒度规范（弱技术层）

description 字段只写**画面意图**，不写渲染实现。

**允许的词汇**：
- 图形类型：圆形、矩形、箭头、坐标轴、折线图、柱状图、路径、图标、文字块
- 布局描述：左侧、右侧、顶部、中央、缩小移至顶部、并排排列
- 动态关系：延伸、散射、聚合、高亮、放大、替换、消失、保留
- 跨镜头衔接：承接上镜标题、图示保留、图示替换为新元素

**禁止的内容**：
- Manim 类名：`Circle`、`VGroup`、`MathTex`、`Arrow`、`Axes`
- 变量名：`title`、`sun`、`rays`
- 代码语法：`.animate`、`Transform`、`FadeOut`、`self.play`

### Manim 叙事 hint 结构

```
【画面描述规范——弱技术层】
description 字段描述画面意图，由代码生成阶段翻译为 Manim 代码。

【可用图形词汇】
几何图形：圆形、矩形、三角形、多边形、路径
连接关系：箭头、双向箭头、连线、虚线
数据图示：坐标轴、折线图、柱状图、散点、数轴
文字内容：标题文字、说明标注、关键公式（用文字描述，如"E=mc² 公式"）

【跨镜头衔接描述方式】
- "承接上镜[元素]，[动作]" ——说明元素延续
- "[元素]保留至旁白结束" ——说明不退场
- "[元素]替换为[新元素]" ——说明视觉替换
- "[元素]完成使命后退场" ——说明叙事退场时机

【退场时机原则】
- 元素完成叙事使命且即将被新内容替代时才退场
- 仅描述"何时退场"意图，不写退场代码
- 若无退场需要，明确写"图示保留至旁白结束"

【示例】
镜头 0："米白背景。中央出现主标题文字，动态写入。保留至旁白结束并延续到下一镜头。"
镜头 1："承接上镜标题，缩小移至顶部保留。左侧出现橙色圆形代表太阳，蓝色射线从太阳向右延伸，末端散射成多条分支，展示光的散射过程。图示保留至旁白结束。"
镜头 2："承接上镜图示。将蓝色短波射线高亮放大，其余颜色射线淡化。右侧出现说明标注'蓝光波长最短'。标题和散射图示完成使命后退场，保留高亮蓝色射线作为下镜视觉锚点。"
```

### Remotion 叙事 hint 结构

```
【画面描述规范——弱技术层】
description 字段描述画面意图，由代码生成阶段翻译为 React/TSX 动画代码。

【可用图形词汇】
SVG 图形：圆形、矩形、路径、线条、多边形
连接关系：箭头、连线
文字层：标题、说明文字、数字标注、公式

【跨镜头衔接】
Remotion 每个 Sequence 是独立作用域。跨镜头持续元素（如背景、顶部标题栏）注明"作为共享层延续"。

【示例】
镜头 0："米白背景。中央主标题文字弹性入场，保留至旁白结束。"
镜头 1："背景和缩小后的标题作为共享层延续。中央展示：左侧橙色圆形代表太阳，蓝色线条向右延伸后分裂成多条散射路径，图示保留至旁白结束。"
```

## 第二部分：代码生成阶段重构（`_ENGINE_CODE_PROMPTS`）

### 新视觉规范系统（Manim）

#### 配色系统——活力暖色扁平

| 角色 | 颜色名 | Hex |
|---|---|---|
| 主色 1 | 草莓红 | `#E8524A` |
| 主色 2 | 橘橙 | `#F07D3E` |
| 主色 3 | 向日葵黄 | `#F5C518` |
| 辅助 1 | 天蓝 | `#4BA3C3` |
| 辅助 2 | 草绿 | `#5BAD6F` |
| 强调 | 薰衣草紫 | `#9B7EC8` |
| 文字/轮廓 | 深炭灰 | `#2C2C2C` |
| 背景 | 米白 | `#F5F0E8`（渲染器设置，代码无需处理）|

同一画面限制：1 主色 + 1 辅色 + 1 强调色，避免彩虹混色。

#### 字体大小规范

| 层级 | 用途 | Manim 写法 |
|---|---|---|
| 主标题 | 视频大标题 | `Text("...", font_size=44)` |
| 节点标签 | 图形旁说明 | `Text("...", font_size=32)` |
| 正文内容 | 关键词、数字 | `Text("...", font_size=28)` |
| 小标注 | 公式辅助说明 | `Text("...", font_size=22)` |
| **禁止** | 裸 `Text("...")` 不加 font_size | — |

#### 画布安全区规范

```
Manim 默认画布：14.2 × 8 单位（宽 × 高），原点在中心
安全区：x ∈ [-6.0, 6.0]，y ∈ [-3.5, 3.5]
边缘缓冲：距边缘至少 0.3 单位
```

规则：
- 所有元素创建后确认坐标在安全区内
- 多元素布局用 `VGroup(...).arrange()` 或明确 `.shift()` 定位
- 大型 VGroup 用 `.scale_to_fit_width(11)` 限制宽度

#### 动画节奏规范

入场动画：
- 图形：`GrowFromCenter`（弹性感首选）或 `DrawBorderThenFill`
- 文字：`Write`
- 淡入（非首选，仅用于背景/次要元素）：`FadeIn`
- 箭头：`GrowArrow`

强调动画：
- 关键结论：`Flash`、`Circumscribe`、`Indicate`
- 数值变化：`CounterclockwiseTransform` 或数字动画

变换动画：
- 图形演变：`ReplacementTransform`
- 属性变化（位置/缩放/颜色）：`.animate`
- 禁止：消灭元素后重建同功能元素

退场动画：
- `FadeOut(element, run_time=0.5)`，统一 0.5s，不拖沓

run_time 选择：
- 简单入场：0.8s
- 标准动画：1.0–1.5s
- 复杂变换：2.0s
- 退场：0.5s

### 退场时机强制检查清单

每个镜头代码生成前，必须隐式维护"画布存量列表"并按以下规则判断：

| 条件 | 动作 |
|---|---|
| 元素本镜头继续被引用或保留 | 不退场，直接使用 |
| 元素已完成使命且本镜头不再出现 | 本镜头开头 FadeOut |
| 元素位置与本镜头新元素重叠 | 本镜头开头 FadeOut 或 ReplacementTransform |
| 背景性持续元素（标题栏等） | 保留，除非叙事要求替换 |

退场时序：退场动画放在本镜头**开头**（先清场，再出新内容）。

代码注释格式（提示词要求 AI 写）：
```python
# === 镜头 N ===
# 画布存量：[列出当前存活元素]
# [元素名] → [保留/退场/替换] 原因：[一句话]
self.play(FadeOut(rays), run_time=0.5)  # rays 完成使命
```

### 变量生命周期规则（保留现有，无变化）

- scene 0 声明的变量在后续镜头可直接引用
- 禁止在不同镜头对同一逻辑元素重复声明同名变量
- 复用元素用 Transform / ReplacementTransform / .animate，不重新声明

## 实现范围

只修改 `chat_provider.py` 中的以下字符串常量：

1. `_NARRATIVE_ENGINE_HINTS["manim"]` — 重写为弱技术层描述规范
2. `_NARRATIVE_ENGINE_HINTS["remotion"]` — 重写为弱技术层描述规范  
3. `_ENGINE_CODE_PROMPTS["manim"]` — 新增配色、字体、安全区、动画节奏、退场检查清单
4. `_ENGINE_CODE_PROMPTS["remotion"]` — 新增配色、画布尺寸（1280×720px）、字体、动画节奏

不涉及函数签名、数据结构、数据库、前端的任何改动。
