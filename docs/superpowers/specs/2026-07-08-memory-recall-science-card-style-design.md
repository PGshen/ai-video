# 风格设计：记忆唤醒·理科卡片

**日期**：2026-07-08  
**状态**：已批准，待实现  

## 概述

面向职场人的初高中数理化知识复习风格。核心定位：用"记忆钩子"叙事策略唤醒观众尘封的学科记忆，配合 Manim 程序化图解动画，在短视频平台（竖屏）传播。

| 属性 | 值 |
|---|---|
| 风格家族名 | 记忆唤醒·理科卡片 |
| 渲染引擎 | Manim |
| 屏幕比例 | 9:16 竖屏（1080×1920） |
| 目标平台 | 短视频（抖音、视频号、B站竖屏） |
| 目标受众 | 职场人，复习初高中数理化 |
| 学科范围 | 数学、物理、化学（初高中） |

---

## 五个风格组件

### 1. 叙事风格（narrative_style）

**记忆钩子三段式**：

**第一段——唤醒（开场 1-2 镜头）**  
用第二人称抛出一个当年学过的场景，触发观众的模糊记忆感：
- "还记得初中物理课讲的这个图吗？"
- "这道题你现在还会做吗？"

开场第一镜头显示**残缺图解**（核心元素用幽灵态隐去），配提问文字，让观众先尝试回忆。

**第二段——重建（中间 3-5 镜头）**  
一步步图解重新推导，语气是"一起回忆"而非"从头教你"：
- 不假设观众记得任何细节
- 每步推导在图解上逐步构建，旁白同步说"对，就是这一步"
- 命名延迟：定律/公式名称在图解完成后再亮出

**第三段——升华（最后 1 镜头）**  
给出超出课本的一句话延伸，让职场人感到学以致用：
- "这个原理，其实就是你手机散热的底层逻辑"
- "下次面试遇到算法题，这个思路直接用"

---

### 2. 叙事节奏（pacing）

- **总时长**：60-90 秒
- **总镜头数**：8-12 个
- **开场唤醒**：不超过 8 秒，前 3 秒必须出现课本感视觉元素
- **卡片镜头**：每张 5-8 秒，图解动画逐步构建，不一次性全出
- **结论镜头**：停留 3-4 秒，配合高亮色块强调
- **节奏感**：每个知识推导步骤对应一个镜头，步骤间用淡入淡出切换，不堆砌

---

### 3. 镜头结构（scene_structure）

每个镜头是一张 Manim 知识卡片，固定三层结构：

```
┌─────────────────────────┐  ← 学科色条带（画面顶部 6%）
│  [学科图标]  镜头主题短语  │
├─────────────────────────┤
│                         │
│      核心图解区           │  ← 占画面中部 50-60%
│   （Manim 逐步构建）      │
│                         │
├─────────────────────────┤
│  💡 核心结论一句话        │  ← 明黄底结论胶囊（画面下方 15%）
└─────────────────────────┘
```

**开场特殊镜头**：显示残缺图解（部分元素 fill_opacity=0.15），配文字"还记得这里是什么吗？"，下一镜头补全揭示。

**安全区约束（竖屏）**：顶部和底部各留 5% 避开手机状态栏/手势条。

---

### 4. 视觉系统（color_scheme）

**画面规格**：1080×1920（9:16），Manim config `frame_width=9, frame_height=16`

**背景**：
- 主背景：纯白 `#FFFFFF`
- 卡片内分区底色：浅灰 `#F4F6F9`

**学科主色**（同一视频内固定，跨镜头不变）：
- 数学：钴蓝 `#2563EB`
- 物理：橙红 `#EA580C`
- 化学：翠绿 `#16A34A`

**结论高亮**：
- 底色：明黄 `#FEF08A`
- 文字：深灰 `#1E293B`

**图解元素**：
- 线条/轴线：深灰 `#1E293B`
- 标注箭头：学科主色
- 幽灵态（未揭示元素）：fill_opacity=0.15，用于开场残缺图解

**字体大小（竖屏手机可读）**：
- 卡片标题：≥52pt 等效
- 图解标注：≥36pt 等效
- 结论文字：≥40pt 等效

**用色原则**：
- 同一视频学科主色固定，不跨学科混用
- 色彩承载信息语义，不做纯装饰用色
- 单镜头主色不超过 3 种（背景色 + 学科主色 + 结论黄）

---

### 5. 动画系统（animation_style）

充分利用 Manim 图形动画特长：

**图解构建**：
- 线条/几何图形：`Create()` 逐笔描线
- 公式：`Write()` 逐字出现，关键变换用 `TransformMatchingTex()`
- 受力图/坐标轴：`GrowArrow()` + `Create()` 逐步添加元素

**元素揭示**（开场残缺图解补全）：
- 隐藏元素在旁白说到时用 `FadeIn()` 补全
- 配合叙事节奏触发，不提前全部显示

**卡片入场**：
- 整张卡片：`FadeIn(shift=UP*0.3)`，0.4s，干净不花哨

**结论胶囊出场**：
- `GrowFromCenter()` 弹出，停留后轻微 `Flash()` 高亮一次

**镜头切换**：
- 统一淡出淡入（0.3s），不使用花式转场
- 保持视觉连续性，让观众专注内容而非切换特效

---

## 实现要点

1. **Manim 竖屏配置**：需在代码生成提示词中明确指定 `config.pixel_height=1920, config.pixel_width=1080, config.frame_height=16`
2. **学科主色注入**：AI 生成代码时，根据当前视频的学科标签自动选择对应主色变量
3. **残缺图解开场**：scene 0 的 prompt 需包含"哪些元素初始为幽灵态、何时触发 FadeIn"的明确指令
4. **结论胶囊复用**：建议抽取为 Manim 自定义 Mobject，所有镜头共用同一实现
