## 命名与本质

**概念传记**:全片是给一个概念立传,传记只回答四个问题——

1. **显形**:这个概念在哪个场景里第一次露出真身?(不必是历史,可以是一个
   当场做给观众看的实验或推演)
2. **机制**:它为什么存在?(大脑/系统的哪个环节出了错)
3. **现身**:它此刻正如何出现在观众自己的生活里?
4. **和解**:观众该拿它怎么办?(情感层面的收束,不是方法论清单)

四个问题是不变骨架;每个问题用什么素材回答,是按选题选取的菜单。

## 一、叙事风格:概念传记·四问骨架

### 〇、选题判定(动笔前判定,决定各菜单取法)
- 概念有**著名起源**(有名有姓的提出者/经典实验/历史事件)→ 显形段可用溯源型锚点
- 概念**当场可演**(观众能在 30 秒内亲历一次)→ 显形段优先用测试型锚点
- 概念靠**数据/推演显形**(概率、统计规律)→ 显形段用推演型锚点
判定一次,全片一致。

### 一、不变内核(风格身份,任何选题不得省略)
1. **十秒认知张力**:开场 10 秒内让观众意识到"我以为的可能是错的"。
2. **概念是唯一主角**:全片只讲透一个概念;概念命名不晚于全片 1/3 处,
   命名自带学科出身与分量感("在统计学与决策科学中,有一个极其致命却
   无处不在的逻辑陷阱")。
3. **锚点场景论证**:全片有一个**核心锚点图示**(源视频=飞机弹孔图),
   承载最主要的推理链,跨章增量推进——推理每前进一步,图示发生且仅发生
   一次对应变化。禁止推理靠旁白空转而图示无事发生。
4. **至少一次完整"预期→打破"**:直觉答案先在画面上立起来(占据正统位置),
   再被推翻(划叉/变灰/翻转)。
5. **一次对照双栏定谳**:论证的关键落点是一组并置面板——
   "直觉看到的 vs 真实发生的",一彩一灰、一立一叉。这是本风格的
   核心论证图式,不同选题只换面板内容,不换格式。
6. **第二人称照镜**:至少一段用"你"重演观众自己的行为,让观众在画面里
   认出自己;全片第二人称不少于 6 处。
7. **一次语域降档 + 对仗金句收束**:结尾从讲解语体切换到贴身文学语体
   (句子拉长、出现比喻、图示退到极简),全片仅此一次;
   金句对仗、回扣锚点意象,**标题即金句**。

### 二、开场钩子菜单(四选一,不叠用)
- **打脸式**:替观众说出常识判断 + 反问 + 干脆否定("……对吗?当然不对了")。
  适用:大众有明确错误直觉的题(幸存者偏差、赌徒谬误)。
- **切身下注式**:把观众放进一个两难处境,逼观众先押注
  ("连开 15 次黑之后,你压红还是压黑?")。适用:决策类偏差。
- **当场测试式**:直接给观众出题,让观众在 30 秒内亲手掉进陷阱
  (Wason 2-4-6:"猜猜这组数字的规律")。适用:可交互复现的偏差,
  钩子与显形段合一,是四种里代入感最强的。
- **反常现象式**:先摆一个"不该发生却反复发生"的现象
  ("为什么每次暴跌之后,人人都说自己早就看出来了?")。适用:现象类。

### 三、显形段锚点菜单(四选一,决定核心锚点图示)
- **历史事件型**:一个真实历史场景做舞台(1913 蒙特卡洛赌场、二战弹孔图)。
  锚点图示 = 该场景的示意图。**人物卡与编年标注仅在此型且提出者
  有名有姓时使用,不是风格必选项。**
- **经典实验型**:复现一个著名实验(Wason 2-4-6、Fischhoff 1975)。
  锚点图示 = 实验材料本身(卡片、序列、问卷)。人物卡可选、可缩为
  一行小字署名。
- **当场测试型**:观众就是被试,实验在观众眼前进行。锚点图示 =
  测试题面。无人物卡。
- **概率推演型**:用数据/模拟让概念自己显形(抛硬币一万次、轮盘序列)。
  锚点图示 = 序列/分布图。无人物卡。
共同纪律:锚点内部必须走完一次"预期→打破";锚点图示建立后跨章继承,
直至该推理链终结。

### 四、机制段菜单(二选一)
- **权威接力型**:第二组研究者给出更深一层解释(卡尼曼&特沃斯基之于
  幸存者偏差)。仅当确有承接关系的后续研究、且能一句话说清其贡献时使用。
- **机制图直击型**:跳过人物,直接画因果链(大脑 → 启发式捷径 → 偏差),
  配规范术语卡(中英对照)。机制说不清提出者时的默认选项。
机制段落点固定:对照双栏定谳(内核第 5 条)在此段或显形段末完成。

### 五、照镜段菜单(域按受众选,形式二选一)
- 域:投资理财 / 信息流与社交媒体 / 职场复盘 / 消费决策 / 健康习惯,
  选观众最可能昨天刚做过的那一个。
- **编号步骤剧**:❶❷❸ 标题逐步重演观众行为,末步揭示真相
  (基金排行榜三步)。适合行为有清晰步骤链的域。
- **场景重演**:单场景简笔小人剧,不编号。适合行为是一瞬间的域
  (刷到一条印证自己观点的帖子、随手点开)。
照镜段允许"预期→打破"第二次发生,但必须换域(不得重复显形段的场景)。

### 六、降档收束菜单
- 降档领域四选一:爱情关系 / 对自己的苛责 / 遗憾与错过 / 家人。
  选与概念伤害面最贴的一个:幸存者偏差→爱情经验;事后诸葛亮→
  对过去决定的自我审判;赌徒谬误→"苦尽甘来"的执念;确认偏误→
  只记得对方好的瞬间。
- 降档标志(三者齐备才算降档):句子变长且出现比喻 /
  图示退到 1-3 个极简元素 / 标题从名词变成叙事句
  ("那个把'每天早安晚安'刻进习惯的人")。
- 金句规则:对仗句式,回扣锚点意象(弹孔→自传/悼词;轮盘→硬币没有记忆;
  迷雾→别用今天的答案审判昨天的自己),冷酷与温情同框。

### 七、禁止
说教开场、揭晓后自夸、无支撑的形容词、结尾喊口号、方法论清单式收尾
("三招教你避免")、为凑传记感硬造人物卡与编年、降档超过一次。

## 二、叙事节奏:五字每秒·书卷呼吸感

- **总量**:成片 150-165 秒,旁白 750-850 字,有效语速约 5 字/秒
  (比群像剧场慢半档,是"读书感"的来源,不是缺陷,不得提速填字)。
  章节 12-14 个,每章旁白 55-80 字(低于 50 字扩写或合并,超 90 字拆章)。
- **五段字数预算**(防止贴下限走):张力段 80-110 字 / 显形段 280-350 字 /
  机制段 100-140 字 / 照镜段 150-200 字 / 降档收束段 120-160 字——
  五段下限之和自然落进全局目标,哪段不够回哪段扩写。
- **节奏曲线:快 - 稳 - 稳 - 缓 - 定格**
  - 快:钩子至概念命名 ≤ 20 秒;
  - 稳(显形):锚点论证 40-55 秒,一句旁白 = 一次图示增量;
  - 稳(机制+照镜):密度与显形段持平,换域不换速;
  - 缓(降档):25-35 秒,密度骤降——这个"突然慢下来"本身就是
    情感信号,必须与前段形成可感知的落差;
  - 定格:金句横幅静止 3-5 秒。
- **密度纪律**:每 1-2 句旁白对应一次画面增量;禁止报幕式过渡
  ("接下来我们看看"),章节切换一律由顶部标题更替完成。
- **连续讲述体**(v2.1):旁白全文是一篇连贯口播稿,句间用时间/因果/转折
  承接("当时/于是/可是/直到"),相邻章节旁白首尾能连读;句长 10-24 字,
  允许复句,禁止电报体与名词短语堆叠。长句与比喻的密集使用只在降档段合法。

## 三、镜头结构:连续画布·五段功能骨架

**形式身份:物理上没有镜头。**全片一张连续暖白画布,零硬切、零转场动画、
相机固定(实测 156 秒仅片尾 1 处硬切)。"镜头"退化为**章节**:
由顶部标题更替 + 中部图示重构界定,相邻章节至少共享一个视觉锚点。

### 五段功能骨架(总计 12-14 章,各段章数弹性)
1. **张力段(1-2 章)**:按钩子菜单实现。当场测试式可直接并入显形段。
2. **显形段(4-6 章,全片最长)**:锚点图示入场 → 增量推理
   (每章只推进一步)→ 直觉方案立起并被推翻 → 锚点结论。
   锚点图示全段连续复用,只做增量,段内禁止清场。
3. **机制段(1-2 章)**:机制解释 + 规范术语卡 + 对照双栏定谳。
4. **照镜段(2-3 章)**:换域重演观众行为;编号步骤剧则一步一章。
5. **降档收束段(2-3 章)**:极简场景章(1-2 章)+ 金句定格章(1 章,
   清场只留对照意象 + 底部金句横幅)。

### 章节纪律(与剧情无关,任何选题一致)
- 段内禁止清场;清场只发生在段间,且以"元素集体淡出、保留 1-2 个锚点"完成;
- **对照双栏格式固定**:左彩右灰(或左立右叉),两栏顶部各配短标题,
  全片可复用 2-3 次,格式不变、内容随段换;
- 一章一个主图示,禁止双图示争抢注意力;
- 标题层是章节的"目录":名词短语(讲解段)→ 编号短语(照镜段)→
  叙事句(降档段),标题语体的迁移本身就是结构信号。

## 四、视觉系统:暖白书卷·衬线学术

### 画布
- 内容画布:暖米白 #FDF8EE,纸面质感;外框深藏青 #1B1B33
  (超宽画幅时作舞台底色,暖白内容区居中如一页书);
- 全片背景不变,**没有黑场**——情感落差由语域降档承担。

### 字体(身份标识)
- 全片一律衬线体(宋体/明朝体系),含标题、标注、数字;
- 术语中英对照:中文衬线 + 英文衬线斜体("选择偏倚 Selection Bias");
- 年代/数据用衬线旧式数字;标题可携带编号(❶❷❸)与判定符号(✓ ✗)。

### 人物卡制(条件组件,非必选)
仅当显形段采用历史事件/经典实验型锚点、且提出者值得出场时使用:
圆角竖卡 + 抽象几何小人(无五官)+ 中文名衬线大字 + 英文名斜体 +
身份标签胶囊;双人物两卡并列以金色 "&" + 年代连接。
其余锚点类型下省略人物卡,署名缩为一行灰色小字或不出现。

### 图示词汇表(按论证步骤选型,开放扩展)
| 论证需要 | 图示类型 |
|---|---|
| 常识/隐喻 | 极简几何隐喻插画(金字塔、直尺、天平、迷雾) |
| 学科出身 | 学科符号拼贴环(齿轮环 + 曲线 + 数学符号) |
| 场景复现 | 对象示意图 + 散点/序列标注(飞机+弹孔、轮盘+连黑序列) |
| 实验材料 | 卡片/题面/问卷(2-4-6 数字卡、事前事后问卷) |
| 排行/数据 | 圆角卡表格,斑马纹,语义色数字 |
| 真相定谳 | 对照双栏面板(彩 vs 灰,✓ vs 红✗) |
| 统计概念 | 散点总体 → 箭头 → 子集;序列独立性用等概率分叉 |
| 观众行为 | 简笔火柴人 + 图标 + 箭头场景 |
| 经验清单 | ✓ 逐条打勾列表(降档段常用:全勾上却仍然失败) |

### 语义色(含义锁定)
- 砖红 #C0392B:错误、损失、否决划叉;青绿 #3DAA8C:成功、正确、存活;
- 芥末金 #E0B84C:焦点圈注、关键箭头、连接符;
- 石板蓝 #5B6E9E / 淡蓝 #A9C4E0:中性主体;
- 灰 + 低透明:沉默、被忽略、已消失(灰 + 大红✗ = 最重终局)。

### 构图
顶部衬线标题(≤14 字)/ 中部单一主图示 / 底部结论横幅卡(仅收尾章)。
负空间 ≥ 60%。

## 五、动画系统:增量书写

**总原则:画布常驻,元素增量进出——动画是"在一页纸上继续写",
不是"换一页"。**相机全程固定,零 zoom / pan / 转场动画。

### 动画词汇表
- 入场:淡入 + 轻微上浮 0.3-0.5s;线条类描边生长;卡片先框架后内容,
  标注延迟 0.2s 跟随;
- 散点/序列逐个点出:0.1-0.2s 间隔,与旁白对齐;
- 圈注:金色椭圆描边 0.4s,专用于"注意这里";
- 箭头生长 0.4s,仅表因果与指向;降档段允许一条 2-3s 慢速长箭头;
- 打勾逐条与旁白列举对齐;大红✗从角到角划过面板 0.3s(最重终局);
- 整体变灰:fill_opacity 降至 0.25-0.35,表"被忽略/沉默",保留原位;
- 让位:旧元素淡出或缩小移位,保留 1-2 个锚点。

### 章节衔接与节拍
- 段内只做增量;段间旧元素集体淡出 0.5s → 新标题淡入,背景不变;
- 一拍一增量(v3.1:每章 4-7 拍,逗号级拆拍),每拍动画铺满时间窗口
  70% 以上,过程优先,拍间静置 ≤0.5 秒;
- 关键揭晓(反转结论、大红✗)独占一拍,前后各留 0.3-0.5s 静止;
- 降档段动画减速减量;收尾逐层淡出,金句横幅定格 3-5s;
- 禁忌:循环动画、装饰粒子、无语义弹跳、相机运动、每章清场重绘。

## 六、泛化验证:三个新选题走一遍骨架

| 段 | 幸存者偏差(原型) | 确认偏误 | 事后诸葛亮偏差 | 赌徒谬误 |
|---|---|---|---|---|
| 钩子 | 打脸式 | **当场测试式**(2-4-6 猜规律,观众亲手掉坑) | 反常现象式("暴跌之后人人都说早看出来了") | 切身下注式("连开 15 次黑,你压哪边?") |
| 显形锚点 | 历史事件型:弹孔图,含瓦尔德人物卡 | 经典实验型:Wason 卡片序列,人物缩为一行署名 | 经典实验型:Fischhoff 事前/事后问卷,或历史事件复盘 | 历史事件型:1913 蒙特卡洛轮盘连黑序列,**无人物卡** |
| 机制段 | 权威接力型(卡尼曼&特沃斯基) | 机制图直击型(大脑只找证实、不找证伪) | 机制图直击型(记忆被结果重写) | 机制图直击型(独立事件 vs 大脑的"平衡直觉") |
| 对照双栏 | 可见的赢家 vs 沉默的失败者 | 你收集的证据 vs 你从不去试的反例 | 事前的迷雾 vs 事后的"清晰" | 你以为的规律 vs 每一次都是 50% |
| 照镜段 | 基金排行榜步骤剧 | 场景重演:刷到印证自己观点的帖子随手点赞 | 步骤剧:复盘会上"我早就说过" | 步骤剧:守号买彩票 / 抽卡"垫刀" |
| 降档领域 | 爱情经验清单 | 只记得对方好的瞬间 | 对昨天的自己的审判 | "苦尽甘来是被欠下的"执念 |
| 金句 | 成功经验是幸存者的自传,不是失败者的悼词 | 我们不是在寻找真相,只是在为相信收集证据 | 别用今天的答案,审判昨天的自己 | 硬币没有记忆,可你有 |

四个选题各自取用不同菜单组合,但**连续画布、锚点增量推理、对照双栏定谳、
第二人称照镜、一次语域降档、对仗金句**六件套完全一致——风格可辨识,
剧情不重复。

## 七、与【群像剧场】的差异对照

| 维度 | 群像剧场 | 概念传记 |
|---|---|---|
| 视觉母题 | 强绑定"可数个体"(小人/粒子/图标) | 开放图示词汇表 + 一个跨章锚点图示 |
| 论证引擎 | 对照处刑/逐步排除/极端推演 | 锚点场景增量推理 + 对照双栏定谳 |
| 镜头观 | 16-20 镜,镜头制 | 连续画布,10-14 章五段功能骨架,零硬切 |
| 情感装置 | 唯一黑场镜头 | 唯一语域降档(讲解体→文学体) |
| 字体气质 | 衬线大数字为主角 | 全衬线书卷体,中英对照 |
| 语速 | 6 字/秒 | 5 字/秒,书卷呼吸感 |
| 适配选题 | 可翻译成"一群个体的处境"的题 | 有可显形锚点场景的概念/效应/偏差类题 |
