## 2. 一句话视觉 DNA

暖象牙白学术讲义底 + 宋体/明朝体编辑排版 + 细线科学图示 + 青绿/琥珀双色
承载语义 + 大面积留白；对象不靠剪辑消失重来，而是沿着推理关系连续变形。

## 3. 视觉系统

### 3.1 色板

以下颜色由去除黑柱和底部字幕后的代表帧量化得到，Hex 受录屏压缩影响，
属于可复用的工程化近似值。

| 角色 | 建议 Hex | 用法 |
|---|---:|---|
| 暖象牙背景 | `#FDFAF6` | 全片固定背景 |
| 主墨色 | `#1C1B19` | 正文、公式、主轮廓 |
| 青绿 | `#2F916A` | 信息、结构、有效传递、正确关系 |
| 深青灰 | `#1F665B` | 青绿系标题和高对比描边 |
| 琥珀金 | `#D2973B` | 能量、时间、关键节点、历史年份 |
| 赭橙 | `#AF6535` | 消耗、热、冲突、否定 |
| 蓝 | `#2D78A8` | 物理载体、中性系统、人物 A |
| 玫红 | `#C94F78` | 人物 B、关系中的另一方 |
| 灰紫 | `#7D7391` | 悖论、未知、交叠关系 |
| 淡薄荷填充 | `#D6ECE5` | 青绿对象的 8%-18% 透明底 |
| 淡金填充 | `#F6EED7` | 琥珀对象的 8%-18% 透明底 |
| 淡紫填充 | `#E1CDE4` | 交集、未知和过渡态 |
| 辅助灰 | `#9BA0A1` | 次级说明、坐标、细边框 |
| 极淡结构线 | `#D5D0D3` | 页面边界、通道和基准线 |

颜色是语义变量，不是装饰变量。稳定画面通常只让两个强调色家族同时占主导；
第三色只用于短暂的状态变化或小面积标注。

### 3.2 字体与编辑排版

- 中文统一使用宋体/明朝体气质的衬线字；公式使用 LaTeX 数学字形
- 标题像书页章题，不像 UI 标题：居中或上方偏中，通常不超过 14 个汉字
- 一句话只给 1-2 个关键词着色，正文仍以主墨色为主
- 历史节点可把四位年份拆成有呼吸感的两组大号数字，例如 `19  48`
- 公式、年代和命题可以独占一屏，靠比例而不是卡片阴影建立层级
- 文字在最终停留态必须无重叠；文字穿插只允许出现在很短的变形过渡帧

### 3.3 图形词汇

所有图形均可由 Manim 基础几何图元、路径和文字构成，保持细描边、低填充、
无拟真材质。

1. 关系图形
   - 圆、交叠圆、Venn 交集、因果箭头、时间轴、通道、刻度条、左右对照
2. 科学对象
   - 原子、波、方形信息包、粒子、容器、活塞、仪表、坐标轴、简单网络
3. 抽象人物
   - 圆头 + 短圆角躯干 + 两点一线表情；不画五官细节和写实肢体
4. 编辑元数据
   - 章节编号圆章、右上角小场景标签、公式名、年份、极淡页面边界
5. 氛围图元
   - 同心圆、扩散环、稀疏粒子、低透明大圆；只做瞬时连接或背景呼吸，
     不与主体争夺注意力

图标随选题替换。参考片中的原子、咖啡杯、麦克斯韦妖、书信和两个人物不是
必选母题；真正必须继承的是「用最少几何图元把抽象关系画成可变状态」。

### 3.4 构图骨架

稳定画面使用四种骨架：

- 章题式：上方短标题 + 中央单一图示 + 极少量脚注
- 公式式：公式或年份居中放大，周围只保留必要解释
- 对照式：左右两个对象或命题，中间用交集、箭头、`VS` 或通道建立关系
- 传递式：源 → 路径/载体 → 目标，粒子或色块沿路径展示过程

共同纪律：

- 负空间约 62%-78%
- 一个稳定画面只有一个主关系，主体 1 个、辅助对象不超过 2 组
- 标题、主体、标注形成清晰三层；装饰永远退到最后一层
- 可用细框和小圆角容器，但不做大面积卡片墙、阴影 UI 或仪表盘

## 4. 动画系统

### 4.1 总体节奏

参考片属于「短促动作 + 清晰停留」而非持续运动。以 10fps 抽样并去掉底部字幕
区域后，约四分之一帧间变化落在明显运动区间；最大的变化尖峰都来自录屏杂质。
工程上可把每个 beat 的活动时间控制在 25%-40%，其余时间用于读图和听旁白。

- 主要动作：0.55-1.10 秒
- 微动作：0.20-0.45 秒，错落间隔 0.06-0.16 秒
- 动作前停顿：0.2-0.4 秒
- 结论态停留：0.8-1.6 秒
- 相机固定；不依赖 zoom、pan 或手持感制造节奏

### 4.2 六类语义动作

1. 建立
   - 先画结构线，再出现主体，最后补标注
   - 同类粒子、节点或文字按阅读方向错落出现
2. 传递
   - 小方块/粒子沿通道移动，波形沿路径生长，箭头从因到果绘制
   - 路径和载体保持在场，让观众看见「什么经过了什么」
3. 转换
   - 同一对象改变形状、颜色或排列表达状态变化
   - 有语义继承时优先匹配变形，不用一次淡出再重新淡入
4. 相交
   - 两段弧线生长为交叠圆，交集最后着淡紫；结论文字在交集稳定后出现
5. 否定/耗散
   - 一次划叉、收缩、碎成粒子或退色即可；动作短促，不叠加抖动和爆炸
6. 推导
   - 公式的项、年份数字、图示节点从上一状态移动到下一状态，
     让结论看起来是「推出来的」，不是凭空展示

### 4.3 跨镜连续性

跨镜按优先级选择：

1. 匹配变形：保留上一镜的核心对象，改变形状、位置或标签成为下一镜锚点
2. 扩散圆承接：已有圆形放大为低透明色场，再收束为下一镜光晕或结构圈
3. 粒子承接：旧对象离散成少量粒子，沿路径汇聚为下一镜主体
4. 整组退场：只有前后确实不存在语义继承时，才在 0.5 秒内整体淡出

除被排除的录屏杂质外，风格不使用黑场和硬切。变形过程允许对象短暂穿插，
但在 0.35 秒内必须落到无碰撞、可阅读的稳定构图。

### 4.4 禁止模式

- 每镜统一套用 `FadeIn + shift`
- 无意义循环、持续漂浮、旋转、弹跳和镜头推拉
- 一次让全部元素同时出现
- 为了“高级感”堆叠网格、粒子、光晕和装饰环
- 上一镜全部清空、下一镜从零重建
- 稳定画面中文本压图、公式压标题、标注相互遮挡
- 复制录屏里的手机 UI、通知、字幕、黑柱、插片和尾屏

## 6. 叙事蓝图

### 6.1 原片的论证骨架

参考片不是按时间顺序介绍科学史，而是围绕一个非对称命题安排证据：

1. 先摆出观众容易默认的等价式：`能量转移 ⇄ 信息传递`
2. 立刻否定，并拆成两个需要独立验证的方向：
   - 信息传递 → 必然伴随能量转移
   - 能量转移 → 未必包含信息传递
3. 对第一个方向建立递进证据链：
   - 1948 香农通信模型：先建立「信息必须经过物理载体」的前提
   - 1961 兰道尔原理：再给出不可逆操作的最低能耗
   - 1871 麦克斯韦妖：用思想实验制造第二定律似乎会失效的危机
   - 1929 西拉德：指出持续工作必须擦除记忆，以擦除能耗解除悖论
4. 用一个单独的「但」转向反方向，以热咖啡向房间散热作为反例：
   能量发生了可测量转移，房间却没有因此「获知」咖啡的存在
5. 补出此前缺失的条件：结构化、可辨识的模式与统计相关性；
   用互信息区分「携带能量的随机噪声」和「真正的信息」
6. 把同一模型迁移到亲密关系：
   争吵/冷战是高能耗低信息，少量有效表达可以是低能耗高信息
7. 以「用更少能量传递更多信息」收束，再用一次光/黑洞隐喻留下余味

历史节点故意不按年代排序。1948 → 1961 → 1871 → 1929 的顺序说明：
证据按论证职责排序，而不是按人物生平排序；命题是主角，人物只是证人。

### 6.2 可复用内核

原片完整使用了「双向拆证—证据接力—边界反例—跨域迁移」，但这是
该选题的最佳路径，不应固化为所有选题都必须满足的六幕结构。真正稳定的
风格身份只有四个叙事锚点：

- 认知入口：观众已有的直觉 + 本片只解决的一个核心问题
- 解释主体：至少两种职责不同的证据递进，而不是案例堆叠
- 边界校准：说明结论的成立条件、失效条件或直觉缺少的一步
- 准确收束：直接回答开场问题，再决定是否需要一句隐喻

双向拆分、历史证人、公式、悖论修复、反方向反例和跨域迁移均为选装模块：

- 只有 A→B/B→A 在逻辑上都有意义时，才使用双向拆证
- 历史人物只有在其贡献不可替代时出现，命题仍是主角
- 公式只有能提供定量边界时出现，不能作为“学术感”装饰
- 悖论只有真实存在且能压力测试命题时使用
- 反例必须帮助定位边界，不能只制造戏剧性
- 形式化术语必须紧跟白话解释，公式负责压缩逻辑，不负责代替解释
- 跨域迁移只有保持变量对应并真正帮助理解时才使用
- 抒情最多在准确结论后出现一次；此前保持平静、克制、学术化

### 6.3 主叙事脊柱选择

AI 在写分镜前先根据选题选择一种主脊柱：

| 主脊柱 | 适用问题 | 常用模块 |
|---|---|---|
| 双向拆证 | 两个概念被误认为等价或可以互推 | 双向拆分、反方向反例、缺失条件 |
| 机制追踪 | 一个现象如何或为何发生 | 现实载体、机制拆解、定量边界 |
| 边界校准 | 一个判断在何时成立或失效 | 正例、边界反例、条件补全 |
| 概念重定义 | 日常直觉与正式定义存在差异 | 直觉案例、正式定义、对照标尺 |

主脊柱决定叙事顺序，模块数量由论证需要决定。不得先选六幕，再把内容
填进空位；输出蓝图时还要列出主动舍弃的模块，抑制 AI 为满足模板而硬凑。

### 6.4 适用边界

优先适用于：

- 「A 与 B 到底是什么关系」类选题
- 「一个现象为何发生」或「一个判断何时失效」类选题
- 日常直觉和正式定义存在显著差异的概念解释
- 必要条件/充分条件、相关/因果、信号/噪声、成本/收益等易被混同的概念对
- 有机制、实验、定量边界或思想实验可组成证据链的学术选题
- 能自然迁移到决策、沟通、组织或日常经验的抽象命题

不适用于纯清单、纯人物传记、新闻盘点、教程步骤和只有单一事实的问题。
若选题无法形成科学上有意义的反方向，不得伪造双向命题；改选机制追踪、
边界校准或概念重定义。跨域迁移仍是选装，不承担补齐结构的任务。

## 7. 风格库落地

风格模板名：`暖白学术图解·语义流变`

组件：

- `narrative_style`：暖白学术图解·证据驱动
- `color_scheme`：暖白学术图解·双色语义
- `animation_style`：暖白学术图解·连续语义变形
- `exemplar`：暖白学术图解·证据更新金样本

叙事组件使用四个必要锚点和按选题选装的证据模块，支持双向拆证、
机制追踪、边界校准、概念重定义四种主脊柱；目标时长为 2-4 分钟。
模板默认组合四个组件；用户仍可在创建项目时替换其中任意组件，
单独复用视觉和动画系统。
